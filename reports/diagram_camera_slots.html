Модуль отображения свободных и занятых мест (мониторинг с камеры)

Схема для пояснительной записки: как в приложении Parking Eye — поверх кадра камеры рисуются полигоны слотов (YOLOv8-seg). Зелёный — slot_free, красный — slot_occupied. Скриншот для Word: Win+Shift+S.

Цепочка обработки (для текста п. 1.2)

Камера / кадр → Отправка на сервер (5 FPS) → YOLOv8-seg: полигоны слотов → Класс: slot_free / slot_occupied → Отрисовка на canvas#overlay → API /api/parking/slots-map
